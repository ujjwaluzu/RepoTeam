# RepoTeam

RepoTeam is a collaborative software project management web application being developed as my CS50W Web Programming with Python and JavaScript final project.

The goal of RepoTeam is to provide teams working on software projects with a central place to organize projects, manage issues and tasks, assign work, and collaborate on development-related work.

## Project Status

The project is currently under development. The current repository contains the initial Django project setup, including the `repoteam` Django project, the `core` application, URL routing, and an initial index page.

More functionality will be implemented throughout development.

## Technologies

The CS50W version of RepoTeam will be built using:

- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript
- React

## Running the Application

Clone or download the repository, create and activate a Python virtual environment, install the required dependencies, and run the Django development server.

Once the server is running, open the local Django development URL in a web browser.
